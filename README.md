# Kisalka Rajapaksha - Portfolio

A personal portfolio website showcasing the work, skills, and experience of **Kisalka Rajapaksha**, a Senior Software Engineer with 7+ years of experience in PHP, Laravel, AWS, and modern web development.

🌐 **Live site:** [kisalka-portfolio.netlify.app](https://kisalka-portfolio.netlify.app/)

---

## ✨ Features

- ⚡ Fast, modern single-page application built with **React 19** and **Vite 7**
- 🎨 Responsive UI powered by **Tailwind CSS** and **Bootstrap 5**
- 🌍 Multi-language support via **react-i18next**
- 📱 Fully responsive design - looks great on desktop, tablet, and mobile
- 🧭 Smooth scroll animations and section-based navigation
- 📬 Contact form integration with **Formspree**
- 🔍 SEO-friendly with Open Graph tags and proper meta descriptions

---

## 🧩 Sections

- **Hero** - Introduction with a typing effect
- **About** - Bio and professional summary
- **Skills** - Core technical skills and expertise
- **Experience** - Career timeline
- **Projects** - Featured work and case studies
- **Contact** - Contact form and social links

## 🚀 Getting Started

### Prerequisites

- **Node.js** 18+ and **npm**

### Installation

```bash
# Clone the repository
git clone https://github.com/kistlak/kisalka-portfolio.git
cd kisalka-portfolio

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

The app will be available at [http://localhost:3000](http://localhost:3000).

### Build for Production

```bash
npm run build
```

The production build is output to the `out/` directory.

### Preview Production Build

```bash
npm run preview
```
